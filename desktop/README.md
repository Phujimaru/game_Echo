# ECHO 5.0 — โปรแกรมสำหรับ Windows

โปรแกรม ECHO เปิดห้องเกมในเครื่องตัวเองได้ เพื่อนต่อเข้ามาผ่าน Radmin VPN ไม่ต้องเช่า server
หน้าเกมข้างในเป็นตัวเดียวกับเว็บ (`client/`) ส่วน server ของห้องคือ `server.js` ตัวเดิม

| ไฟล์ | หน้าที่ |
| --- | --- |
| `main.js` | หน้าต่างเต็มจอ, ปุ่มลัด (F11 เต็มจอ / F10 ออกจากห้อง), สร้างห้อง/เข้าร่วม, ด่านตรวจทั้ง 3 |
| `room.js` | เปิด `server.js` เป็น process แยก (`utilityProcess`) เมื่อกด "สร้างห้อง" |
| `updater.js` | ด่านที่ 1 — เวอร์ชันต้องตรงกับ R2 มีใหม่ = โหลด ติดตั้ง แล้วเปิดใหม่เอง |
| `media.js` | ด่านที่ 2 — โหลดไฟล์สื่อตาม manifest มาแคชในเครื่อง และตอบไฟล์สื่อให้หน้าเกมจากแคช |
| `launcher/` | หน้าแรกของโปรแกรม |
| `config.js` | URL ของ R2 |
| `scripts/` | เตรียมโค้ดเกม (`stage-game.js`), สร้าง manifest, ปล่อยเวอร์ชัน (`release.js`) |

ด่านที่ 3: ตอนเข้าร่วม โปรแกรมถาม `/version` ของห้องก่อน ต้องตรงกันทุกตัวเลข
และห้องที่โปรแกรมเปิดจะรับเฉพาะโปรแกรม ECHO เวอร์ชันเดียวกัน เปิดผ่านเบราว์เซอร์ตรง ๆ ไม่ได้

## รันตอนพัฒนา

```
cd desktop
npm install
npm start
```

- `ECHO_WINDOWED=1` — เปิดเป็นหน้าต่าง ไม่เต็มจอ
- ตอน dev จะข้ามด่านที่ 1 และ 2 และใช้ไฟล์สื่อจาก `client/public` ตรง ๆ
  ตั้ง `ECHO_MEDIA_MANIFEST` (path หรือ URL) / `ECHO_UPDATE_URL` ถ้าอยากทดสอบด่านเหล่านั้น

## ปล่อยเวอร์ชันใหม่

1. แก้ `"version"` ใน `desktop/package.json` (เช่น `5.0.0` → `5.0.1`) — ทุกเครื่องต้องเลขตรงกันถึงเข้าห้องกันได้
2. ใส่กุญแจ R2 ในไฟล์ `.env` ที่ราก repo ครั้งแรกครั้งเดียว (ดูหัวข้อท้ายไฟล์ `.env.example`)
3. ลองดูก่อนว่าจะอัปอะไร: `npm run release -- --dry-run`
4. ปล่อยจริง: `npm run release`

สคริปต์จะ build exe แล้วอัปขึ้น R2 ตามลำดับ: ไฟล์สื่อที่เปลี่ยน → `updates/media-manifest.json` → exe → `updates/latest.yml`
เครื่องเพื่อนจะอัปเดตเองตอนเปิดโปรแกรมครั้งถัดไป (ไม่มีอัปเดตกลางแมตช์)

- `--prune` ลบไฟล์สื่อบน R2 ที่ไม่มีในเกมแล้ว (เช่นของตัวละครที่ถูกถอด) — ลองกับ `--dry-run` ก่อนเพื่อดูรายชื่อ
- เว็บเวอร์ชันใช้ไฟล์สื่อบน R2 ชุดเดียวกัน

## ข้อความส่งให้เพื่อน (ครั้งแรก)

> **วิธีลง ECHO**
> 1. โหลดตัวติดตั้ง: `https://pub-246229b6130d42e19ea95765c029663e.r2.dev/updates/ECHO-Setup-5.0.0.exe`
> 2. เปิดไฟล์ ถ้า Windows ขึ้นจอฟ้า "Windows protected your PC" ให้กด **More info** แล้วกด **Run anyway** (โปรแกรมไม่ได้ซื้อใบรับรอง เลยโดนเตือน — เตือนแค่ครั้งแรก อัปเดตครั้งต่อไปไม่เตือน)
> 3. เปิดครั้งแรกจะโหลดไฟล์เกมประมาณ 1.1 GB รอให้ครบ (ปิดกลางทางได้ เปิดใหม่โหลดต่อ)
> 4. ลง **Radmin VPN** แล้วเข้าเครือข่ายเดียวกัน
> 5. คนเปิดห้องกด **สร้างห้อง** แล้วส่ง IP ที่ขึ้นต้น `26.` ให้คนอื่น — ถ้า Windows ถามเรื่อง Firewall ให้ติ๊กทั้ง Public และ Private แล้วกดอนุญาต
> 6. คนอื่นกด **เข้าร่วม** แล้วใส่ IP นั้น
